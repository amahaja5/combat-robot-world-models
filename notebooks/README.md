# Notebooks

This directory contains Jupyter notebooks for the Combat Robot World Models project.

## Available Notebooks

### combat_robot_world_model.ipynb (Coming Soon)
Full tutorial for:
- Downloading training data
- Processing videos
- Training the world model
- Evaluating strategies
- Optimizing material allocation

## Usage

### Local

```bash
jupyter notebook notebooks/combat_robot_world_model.ipynb
```

### Google Colab

Upload the notebook to Google Colab and enable GPU:
1. Runtime → Change runtime type → GPU → T4
2. Run all cells
3. Follow the prompts

## Requirements

- Python 3.10+
- See `requirements.txt` for dependencies
- GPU recommended (16GB+ VRAM)
